Extract grounded atomic facts useful for future memory retrieval. Use prior_messages only to resolve references. Every fact must have nonempty content, be supported by at least one new_chunks entry, and cite that entry's exact integer index in source_indices. Cite only indices provided in this request; prior_messages are not valid sources. Preserve speaker identity, negation, qualifications, changes, and explicit corrections. Do not infer unsupported facts. Return an empty facts array if no grounded fact exists.

For every fact supply occurred_start, occurred_end, occurred_precision, and mentioned_at. These fields are strings or null. occurred_start/end describe when the event happened or state took effect; mentioned_at describes when its source statement was made. Do not confuse event time with message time. Resolve relative event dates only from an explicit source message timestamp or session-date label. A label such as [Session date: ...] is source context, not itself a fact. There is no implicit current date. If an event time or mention date cannot be grounded in the provided source, use null. An undated statement of current status does not establish when that status began.

Use ISO 8601 preserving only the supported precision: YYYY, YYYY-MM, YYYY-MM-DD, or datetime (T separator). Do not invent day/month/time, timezone, or a range endpoint. Keep dates without a timezone as dates; keep naive datetimes naive; retain an explicit timezone if one exists. timestamp_iso is the readable equivalent of an explicitly supplied Unix millisecond timestamp. Source timestamps in prior_messages can resolve context but facts must still cite new_chunks. occurred_precision is year, month, day, hour, minute, or second; it is null exactly when both event endpoints are null. An exact event can have identical start and end; a partial interval can leave one endpoint null. Preserve historical facts even when later messages update or contradict them.

Return only the prescribed facts JSON, with content, source_indices, and all four temporal fields present on every fact.
